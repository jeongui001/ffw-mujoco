# 자동 테스트

```bash
source .venv/bin/activate
python -m unittest discover -s tests -v
```

`test_control.py`는 상위 작업 보존, 제한 내 IK, SO(3) 오차, 양손 위치·회전 추종,
팔 우선 정책, 공유 리프트와 반대 손 높이 유지, 좌우 전환, 명령 속도·가속도 및 힘 제한,
도달 불가 입력, 잘못된 입력과 오래된 백그라운드 계획의 폐기를 검증합니다.
초기 팔꿈치의 직각, 서로 마주보는 손바닥·전방 손가락 방향과 초기 자세의 물리 유지도 검증합니다.
양손 엄지·네 손가락의 분리 제어, 접기·다시 펴기, 손가락 명령 속도 제한과 팔 제어 병행도 검증합니다.
양손 엄지의 열린 방향이 손바닥 바깥쪽 법선과 일치하고 네 손가락과 직각인지,
접을 때 엄지 끝이 손바닥 쪽으로 가까워지는지도 검증합니다.
전체 조인트 조회, 직접 제어/IK 모드 분리와 복귀, 모드 변경 시 이전 계획 폐기,
오른손 기준 IK 지표, 실제 호출 간격 기반 주파수/EMA와 일시정지 시간 처리도 검증합니다.
화면을 열지 않고 실제 MuJoCo 모델과 물리 진행을 사용합니다.

원본 모델 로딩과 이름 매핑만 확인하려면 `python scripts/check_model.py`를 실행합니다.
